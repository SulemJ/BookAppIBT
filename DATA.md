# Book Store Query Strategy

| Query              | Key                                                           | Refresh Rule                             | Justification                                                                                                                                                                                                                                                                              |
| :----------------- | :------------------------------------------------------------ | :--------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Order Tracking** | `/api/orders/${id}`                                           | `refreshInterval: 10000`, `fallbackData` | Server fetches initial data for instant first paint. SWR polls every 10 seconds to update shipping and tracking details.                                                                                                                                                                   |
| **Book Search**    | `/api/books/search?q=${debouncedTerm}&page=${page}` or `null` | `keepPreviousData: true`                 | Uses a debounced key to prevent firing API requests on every keystroke. When empty, the key is `null` to bypass fetching entirely. `keepPreviousData` prevents the list from flashing empty between typed letters. Page is included in the string to ensure unique cache entries per page. |
